# StarSaber 要件定義

## 1. プロジェクト概要
- **目的**: Apple Vision Pro 向けの一人用ライトセイバーバトル体験を提供し、直感的なジェスチャ操作と没入感を重視したショートプレイゲームを短期間で完成させる。
- **対応デバイス**: Apple Vision Pro（visionOS 26 / SDK 26）。
- **ターゲットユーザー**: SF/スターウォーズ風の演出を好み、最新デバイスでの新規体験を求めるカジュアルゲーマー。
- **ビジネスゴール**: 個人開発作品としてのポートフォリオ公開。visionOS 26 対応の没入型タイトル実装ノウハウを蓄積する。

## 2. MVP スコープ
- シングルウェーブ制（1～2 分想定）のバトルシナリオ。
- プレイヤーはライトセイバー 1 本を操作し、ドロイド型敵複数体と交戦。
- 3 種の基本アクション: 攻撃（斬撃）、パリィ、フォースプッシュ（クールダウン制）。
- ヒット/被弾判定、HP 表現、ゲームオーバー・勝利判定。
- シンプル UI（HP バー、スコア、ウェーブ情報、再挑戦ボタン）。

## 3. ユーザーストーリー
1. プレイヤーはアプリ起動後、導入チュートリアルでライトセイバーの構え/操作を学ぶ。
2. ウェーブ開始で敵が出現し、攻撃を繰り出す。プレイヤーは回避・パリィ・反撃で応戦する。
3. 敵を全滅させるか、プレイヤー HP が尽きるまでバトルが継続。結果画面でスコアと評価を確認できる。
4. プレイヤーは「再挑戦」で即座に同じウェーブに戻れる。

## 4. ゲームプレイ要件
- **ライトセイバー挙動**: ハンドトラッキングと 6DoF を利用し、リアルタイムで手の位置・回転と刀身を同期。攻撃時には軌跡エフェクトとサウンド再生。
- **敵 AI**: 単純なステートマシン（巡回→攻撃準備→攻撃→待機）。攻撃パターン 2 種（水平斬り、突き）。
- **ダメージ判定**: コライダーによる衝突判定。攻撃の軌跡に基づきヒット検出。パリィ判定は攻撃軌道とセイバー角度の角度差条件で成功。
- **フォースアビリティ**: クールダウン 8 秒。発動時に敵をノックバックし、短時間スタンさせる。
- **難易度調整**: 敵体力/攻撃頻度のパラメータ化。MVP では固定値とし、後続でテーブル化可能にする。

## 5. 操作/入力
- **ハンドトラッキング**: 右手でセイバー保持（HandTrackingProvider）。グリップジェスチャで起動、ピンチでフォース発動。
- **ヘッド/アイトラッキング**: ヘッドポジションに応じたカメラ制御。ターゲット選択は視線固定＋ピンチ（MVP では自動選択）。
- **UI 操作**: SwiftUI ボタンを空間アンカーに配置し、視線＋ピンチで操作。

## 6. 体験演出
- **ビジュアル**: RealityKit で 3D アセット読込。ライトセイバーはシェーダーモディファイアでグロー表現。敵は簡易的なドロイドモデルとする。
- **パーティクル**: 斬撃時の火花、フォース時の衝撃波を RealityKit Particle API で実装。
- **オーディオ**: SpatialAudio で環境音（ハンガー/宇宙船内）と武器効果音を配置。HRTF 対応。
- **UI 演出**: 戦況に応じて UI カラーを変更。被弾時に画面フラッシュ効果。

## 7. 技術スタック
- **言語/フレームワーク**: Swift 5.9、SwiftUI、RealityKit、ARKit / Vision Framework（ハンドトラッキング）、GameplayKit（AI ステート管理）。
- **アセット制作**: Reality Composer Pro、Blender（外部で軽量モデル調整）。
- **ビルド環境**: Xcode 15.2、visionOS 26 SDK、ターゲットデプロイメント visionOS 26。
- **補助ライブラリ**: Combine（ゲームステートのリアクティブ管理）、SceneUnderstanding（空間メッシュ取得）。
- **開発ツール**: Git、GitHub Issues/Projects、TestFlight（後続配布）。

## 8. 非機能要件
- **パフォーマンス**: 90fps を目標。Draw Call は 200 未満を維持。ライトセイバーコア部分は GPU パーティクルを使用しない。
- **安定性**: メモリ使用 2 GB 未満。クラッシュレポートは Xcode Organizer で随時確認。
- **UX**: プレイ開始まで 15 秒以内。モーションを極力滑らかにし VR 酔いを抑制。
- **テレメトリ**: MVP ではローカルログのみ。将来的に MetricKit を導入しクラッシュ/パフォーマンス収集。

## 9. ロードマップ（6 週間想定）
1. **Week 1**: プロトタイプ立ち上げ、ハンドトラッキングでライトセイバー表示。HUD 下描き。
2. **Week 2**: 敵アセット仮組み、ステートマシン実装、ヒット判定試作。
3. **Week 3**: パリィ/フォースギミック実装、ゲームループ基盤完成。
4. **Week 4**: ビジュアルエフェクトとサウンド統合、HUD 仕上げ。
5. **Week 5**: チュートリアル導線、バランス調整、バグ修正。
6. **Week 6**: テスト、ビルド安定化、ストア素材準備（任意）。

## 10. リスクと対応
- **ハンドトラッキング精度不足**: ジェスチャ検出に閾値を設け、誤検知時にはビジュアルフィードバックで補助。
- **高負荷アセット**: LOD 導入とデカール削減で最適化。必要に応じて Shader Graph を簡略化。
- **個人開発での工数不足**: MVP 前提で機能優先順位を明確化。後回しリスト（敵バリエーション、ストーリーモード等）を管理。
- **IP リスク**: スターウォーズに類似する名称/デザインはオリジナルアセットに置換し、侵害しないよう注意。

## 11. 後続アイデア（MVP 後）
- 複数ウェーブとボス戦追加。
- デイリー/スコアランキング（Game Center）。
- 左利きモード、デュアルセイバー対応。
- フォースアビリティの追加（ライトニング、スロー）とスキルツリー化。
- ストーリーミッションや NPC との対話シーン。
